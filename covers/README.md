# Cover images

Drop artifact cover images in this folder, then reference them from `data.js`
like `image: "covers/your-file.jpg"`.

Tips for bulk uploads:
- Keep filenames simple: lowercase, words separated by hyphens, no spaces or
  parentheses (e.g. `the-waves.jpg`, not `The Waves (1931).jpg`).
- JPG or PNG are fine. Portrait covers (roughly 2:3) look best in the grid, but
  any size works.
- You can upload many at once: on GitHub, open this folder → **Add file →
  Upload files**, then drag the whole batch in and commit.

(You can also skip files entirely and point `image` at a full `https://…` URL.)
